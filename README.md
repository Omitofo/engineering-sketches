# Engineering Sketches

Small, polished, public projects meant to demonstrate real software engineering skills.

These are intentionally focused and completable. The goal is quality over quantity — clean architecture, good documentation, thoughtful UX, and solid engineering practices.

---

## Project Ideas

### 1. `ctx-pack`
**CLI tool that packages a folder into clean, structured context for LLMs.**

- Respects `.gitignore` + custom ignore rules
- Generates a clean file tree + optional file summaries
- Token/size estimation
- Outputs markdown or JSON
- Good CLI design (flags, error handling, help text)

**Why it’s strong:** Extremely relevant to AI/context work while remaining general-purpose and useful to other developers.

**Status:** Idea

---

### 2. `stream-kit`
**Small library of high-quality streaming AI chat UI primitives.**

- Streaming message component with smooth rendering
- Tool call / intermediate step indicators
- Loading, error, and retry states
- Clean TypeScript + excellent documentation
- Framework-friendly (React-first, possibly vanilla)

**Why it’s strong:** Demonstrates frontend craftsmanship and modern AI UX taste.

**Status:** Idea

---

### 3. `local-memory`
**Tiny local-first memory system for agents.**

- Store and retrieve facts/notes with tags
- Simple but clean search
- SQLite or structured file-based storage
- Small, intentional API surface
- Good data modeling and architecture

**Why it’s strong:** Shows systems thinking and clean data design in a focused package.

**Status:** Idea

---

### 4. `focus-ritual`
**A beautiful small local app (or CLI) for focused work sessions + principles capture.**

- Short focused sessions
- Lightweight note/principle capture
- Extremely polished UI and experience
- Local storage only

**Why it’s strong:** Product taste + attention to detail. Can be made surprisingly delightful.

**Status:** Idea

---

## How this repo will evolve

- Each idea will live in its own folder once we decide to pursue it.
- Only one (or two) will be fully built and polished.
- The rest may stay as documented ideas or light sketches.

Pick the one you want to pursue first and we’ll start building it properly.

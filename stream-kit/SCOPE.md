# stream-kit

Small library of high-quality streaming AI chat UI primitives.

## Core Goals
- Make beautiful, production-feeling streaming chat UIs easy
- Focus on the hard parts: streaming rendering, tool calls, states
- Keep the surface area small and intentional

## Possible Features (MVP → Nice-to-have)

### MVP
- Streaming message component (handles partial tokens smoothly)
- Basic message list
- Loading / typing indicator
- Error state + retry
- Clean TypeScript types

### Nice-to-have
- Tool call / intermediate step visualization
- Smooth animations
- Markdown + code block rendering
- Accessibility basics
- Framework adapters (React first)

## Tech Direction (suggestion)
- React + TypeScript
- Minimal dependencies
- Excellent documentation and examples

## Definition of Done
- Publishable as a small package
- Great README with live examples or clear screenshots
- Type-safe and well-documented
- Feels premium and intentional

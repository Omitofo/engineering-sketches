# focus-ritual

A beautiful small local app (or CLI) for focused work sessions + principles capture.

## Core Goals
- Make short, intentional focus sessions feel good
- Allow lightweight capture of principles, notes, or insights
- Extreme attention to polish and experience

## Possible Features (MVP → Nice-to-have)

### MVP
- Start a timed focus session
- Simple note capture during or after the session
- Local persistence
- Clean, calm UI (or excellent CLI experience)

### Nice-to-have
- Principles / values library
- Session history
- Gentle stats (streaks, total focus time)
- Beautiful empty states and micro-interactions
- Optional dark/light mode

## Tech Direction (suggestion)
- Web: React + Vite + localStorage or SQLite (via wasm)
- Or a polished CLI if we want to stay terminal-native
- Design should feel intentional and calm

## Definition of Done
- Feels delightful to use
- Looks and behaves like a real product, even if small
- Clear README + screenshots
- Local-only (no accounts, no backend)
